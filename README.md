# Sistema web de perfumería

## Descripción

Proyecto académico de desarrollo web enfocado en una tienda de perfumería. El repositorio contiene archivos de interfaz y scripts PHP relacionados con la gestión de productos y usuarios.

## Objetivo

Aplicar conocimientos de desarrollo web mediante la organización de páginas, estilos y archivos de programación para construir una aplicación relacionada con la venta de productos de perfumería.

## Tecnologías

- **PHP:** programación del lado del servidor.
- **HTML:** estructura de las páginas web.
- **CSS:** diseño y presentación de la interfaz.
- **JavaScript:** presente en el proyecto, según los archivos incluidos.

## Estructura del proyecto

Entre los archivos del repositorio se encuentran:

- `productos.php`: archivo relacionado con la sección de productos.
- `registro.php` y `registro.html`: archivos relacionados con el registro.
- `usuarios.php`: archivo relacionado con los usuarios.
- `principal.php`: página principal de la aplicación.
- `style.css` y otros archivos CSS: estilos de la interfaz.
- `conexion.php`: archivo de conexión a la base de datos, si está configurado para ello.

## Ejecución

Para revisar o ejecutar el proyecto localmente:

1. Instalar un entorno de desarrollo PHP, como XAMPP.
2. Colocar el proyecto en la carpeta `htdocs`.
3. Configurar la conexión a la base de datos si la aplicación la requiere.
4. Iniciar los servicios necesarios y abrir el proyecto desde el navegador local.

Los pasos exactos pueden variar según la configuración original del proyecto.

## Aprendizajes

Este proyecto permite documentar la práctica de conceptos de desarrollo web, organización de archivos, estilos de interfaz y programación con PHP.
